# 排障手册

按症状查。每条都给出"先确认什么、再怎么处理"。

---

## 1. 插件装好后界面里看不到

**先确认**

- DSH 版本 ≥ 0.1.5-rc.1（`dsh --version`，或桌面端「关于」）
- 插件出现在列表里：`dsh plugin list`
- 插件目录确实被链上/装上了：`~/.dsh/profiles/desktop/node_modules/dsh-we-wallpaper`

**处理**

1. 完全退出 DSH（macOS 用 ⌘Q，不是关窗口）再打开
2. 开发态软链安装时，确认 `lib/client.js` 存在；没有就 `npm run build`
3. 还不行就先移除再装：
   ```bash
   dsh plugin remove dsh-we-wallpaper
   dsh plugin add /path/to/dsh-wallpaper-engine-main
   ```

---

## 2. 壁纸列表是空的 / 扫不到壁纸

**先确认**

- Wallpaper Engine 是否装在本机，创意工坊壁纸是否下载完成
- Steam 库是不是默认位置（插件会读 Steam 的库配置，多磁盘一般也能找到）

**处理**

- 非默认库、或壁纸被挪到别处：用环境变量指路后重启 DSH
  ```bash
  export DSH_WE_STEAM_ROOT="/path/to/steamapps/common/wallpaper_engine"
  ```
- 确认当前用户有读权限
- 不用 Wallpaper Engine 也能玩：直接上传 JPG / PNG / MP4（上限 512MB）

---

## 3. 场景壁纸黑屏、不动、或提示"实时渲染失败"

插件会自动降级：实时渲染失败 → 试内嵌视频 → 再退到静态画面。所以看到画面但不动，通常是降级后的静态帧。

**处理**

1. 打开「播放 → 实时渲染」开关，关掉再打开，重试一次
2. 降低「实时帧率」（60 → 30 → 15）和「启动最长等待时间」相关的期待值
3. 确认显卡驱动正常；远程桌面、虚拟机、无 GPU 环境通常渲染不了
4. 想先看清楚内容：用「自定义画面」抓一张实时帧，或导入截图顶上
5. 具体原因看诊断日志（见第 10 节）

---

## 4. 视频壁纸卡顿、黑屏、或只有声音

**先确认**

- 视频编码浏览器能不能直接播（MP4/H.264 最稳，HEVC/AV1 可能不行）
- 缓存目录所在磁盘还有空间

**处理**

- 打开「播放 → 抽帧转码」：把高帧率/高码率视频转成低帧率再播，转码进度会显示
- 降低「帧率上限」
- Windows 上用 Edge 且出现下载/投屏悬浮条：打开「系统 → 兼容性 → Edge 兼容」
- 换一张壁纸测试，排除单个文件损坏

---

## 5. 没有声音

1. 「壁纸库 → 当前壁纸」里确认是「🔊 音乐开」，音量不是 0
2. 系统音量、输出设备、静音状态
3. 这张壁纸本身有没有音轨（视频壁纸、带音频的场景壁纸才有）
4. macOS 上系统音频频谱需要「录音」授权，和壁纸音轨是两件事

---

## 6. 音频频谱不动 / 不跟随音乐

- 频谱依赖本机媒体桥读取系统播放器。先播放一首歌，再回来看
- macOS：首次会弹「音频录制」授权；拒绝了就去「系统设置 → 隐私与安全性 → **音频录制**」里勾选 DSH Desktop（或你的终端 / DSH 宿主），然后重试
- 媒体桥是首次需要时下载的，网络不通会退回模拟频谱；换个网络重试
- 有些播放器不向系统上报播放信息，这类播放器读不到歌名和频谱

---

## 7. macOS「启动时铺满屏幕」没生效

按顺序授权，然后 **⌘Q 完全退出再打开**：

1. 系统设置 → 隐私与安全性 → **辅助功能** → 勾选 `osascript` 和 `DeepSeek Harness`
   - 列表里没有 `osascript` 就点 `+`，按 ⌘⇧G 输入 `/usr/bin/osascript`
2. 系统设置 → 隐私与安全性 → **自动化** → 允许「DeepSeek Harness」控制「System Events」

设置页里也有同一份指引。

---

## 8. 玻璃效果没变化 / 某些区域不透明

- 确认「外观 → 玻璃」总开关是开的
- 不同区域是分开控制的：设置窗口、对话框、思考条、浮层、左栏、标题栏，检查对应分区
- 深色模式有单独一套参数（「深色单独设置」）
- 桌面壳与浏览器表现可能不同；某些宿主版本不支持标题栏材质

---

## 9. 费用数字不显示 / 对不上

- 「系统 → 费用统计」里确认开关是开的
- 费用来自宿主的用量记录，宿主没提供数据时这里就是空的
- 高峰/低谷倍率、缓存命中与未命中的单价由宿主规则决定，插件只负责显示

---

## 10. 收集诊断信息（提 issue 前）

1. 打开诊断日志：
   ```bash
   export DSH_WE_LOG_LEVEL=info   # 默认只输出 warn 及以上
   ```
   重启 DSH，复现问题，把宿主日志里带 `[wallpaper-engine]` 的行截出来
2. 说明：DSH 版本、插件版本、操作系统、壁纸类型（场景/视频/网页/图片）、壁纸来源（Steam/上传）
3. 能截图就截图，场景类问题附上壁纸卡片上的报错文字

---

## 11. 数据、缓存与卸载

- 数据目录：`~/.dsh-wallpaper-engine/`
  - `config.json`：全部设置
  - `cache/`：转码、抽帧、缩略图（可在「系统 → 缓存位置」改）
  - `fontsets/`、`glass-presets/`：你导入的预设
- 改缓存目录不会自动搬旧文件，旧缓存可以手动删
- 卸载：`dsh plugin remove dsh-we-wallpaper`；想彻底清干净再删数据目录

---

## 12. 上传失败

- 只支持 JPG / PNG 图片和 MP4 视频
- 单文件上限 512MB
- 上传目录不可写时，在「壁纸库 → 自定义壁纸」里换一个目录
