## 候选功能（未开工）

### 通用音乐律动（视频 / 图片 / 网页壁纸）
- 背景：现在只有场景壁纸能响应音频（场景脚本读 `__wp` 音频桥）；视频壁纸是固定像素，没有反应。
- 方案：在壁纸上叠一层**由频谱驱动的效果层**，不改变视频本体：
  - 底部光晕/波纹随低频起伏
  - 全屏粒子随节拍跳动
  - 边框/色温随能量变化
- 建议实现：Canvas/WebGL 单层，30fps 上限，只在检测到音频（`running`）时绘制；复用现有的遮挡/失焦/电池暂停规则。

## 已知问题（暂不处理）

- **大肥鱼转圈时边缘轻微裁剪**：转圈帧角色张开超出卡片左右边界，用户判断影响很小，暂不修改。
- **插件卸载按钮不可用**：宿主调用 `pnpm`，本机未安装 pnpm，报 `ENOENT`。绕法：改 `~/.dsh/profiles/*/package.json` 依赖后 `npm install`。
