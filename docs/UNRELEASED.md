## 候选功能（未开工）

### 通用音乐律动（视频 / 图片 / 网页壁纸）
- 背景：现在只有场景壁纸能响应音频（场景脚本读 `__wp` 音频桥）；视频壁纸是固定像素，没有反应。
- 方案：在壁纸上叠一层**由频谱驱动的效果层**，不改变视频本体：
  - 底部光晕/波纹随低频起伏
  - 全屏粒子随节拍跳动
  - 边框/色温随能量变化
- 建议实现：Canvas/WebGL 单层，30fps 上限，只在检测到音频（`running`）时绘制；复用现有的遮挡/失焦/电池暂停规则。
- 资源预估（Apple Silicon 核显）：
  - 低配（少量粒子 + 30fps）：约 1–3% GPU
  - 高配（全屏粒子 + 60fps）：约 6–15% GPU
  - 频谱轮询本身（10Hz 小 JSON）可忽略
- 需要的设置项：开关、强度、帧率上限、（可选）只在高频/低频响应。
